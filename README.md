مُسبِّحة — برنامج تسبيح بسيط وخفيف لأجهزة ويندوز، يتيح للمستخدم عدّ الأذكار بضغطة مفتاح واحدة دون الحاجة لفتح أي نافذة أو مغادرة ما يعمل عليه. يتميّز بإمكانية تخصيص حروف الزيادة والحفظ حسب رغبة المستخدم، وتُحفظ هذه الحروف داخل ملف السكربت نفسه فلا حاجة لإعادة الإعداد في كل مرة.

صُمِّم البرنامج ليكون:

سهلًا: ضغطة واحدة تزيد العدد، وضغطة واحدة تحفظ وتغلق.

مرنًا: المستخدم يختار الحروف التي تناسبه (يجب أن تكون غير مستخدمة في برامجه الأخرى).

خفيفًا: لا يحتاج تثبيتًا ولا موارد كبيرة.

يحفظ تلقائيًا: العدد يُحفظ في ملف نصي عند الخروج، ويُستعاد عند التشغيل التالي.
